How should the panels behave as the workspace shrinks?

The right panel (Activity, Diff, Computer, Terminal) breaks when it is dragged narrow. The tab strip clips, and the Computer card hides its own Start button. The main panel uses window-width breakpoints, so it ignores its real size. Each option below handles this with a different strategy, using the same sample workspace. Open one to resize it, switch the computer's state, and try other window sizes.

Recommendation

Option 4, Collapse + drawer. It is the only option that keeps every panel usable at every window size. Panels never squeeze below a working width. They collapse to a rail instead, and small windows get a drawer rather than losing the right panel. Inside the panel it uses the same reflow as Option 1 (scrolling tabs, a Computer card that grows to fit), so most of the code change is shared. Option 3's snap sizes could be added later if free resizing still produces awkward widths.
